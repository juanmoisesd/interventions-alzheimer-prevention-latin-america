## Overview

Systematic review of evidence-based interventions for Alzheimer's disease prevention in Latin American populations (2000-2024). This dataset compiles data on preventive strategies, clinical trials, public health initiatives, and behavioral interventions targeting Alzheimer's risk reduction across Latin America.
